‏1. آشنایی با Git و GitHub

‏Git چیست و چه کاربردی دارد؟
‏Git یک سیستم کنترل نسخه است که تغییرات پروژه و کدها را مدیریت و ذخیره می‌کند.

‏GitHub چیست و چه تفاوتی با Git دارد؟
‏GitHub یک پلتفرم آنلاین برای ذخیره و اشتراک‌گذاری پروژه‌های Git است. Git روی سیستم برای کنترل نسخه استفاده می‌شود، اما GitHub برای ذخیره و مدیریت پروژه‌ها در اینترنت است.

‏برای تمرین‌های خود یک Repository در GitHub ایجاد کنید.
‏در GitHub یک Repository ایجاد کرده و تمرین‌های خود را داخل آن قرار دهید.

‏هر تمرین را در Repository قرار دهید.
‏هر تمرین را می‌توان به صورت یک فایل یا پوشه جداگانه داخل Repository قرار داد.

‏دسترسی Repository را برای من ارسال کنید.
‏لینک Repository را برای استاد ارسال کنید تا تمرین‌ها بررسی شوند.

‏3. HTTP و HTTPS

‏HTTP چیست؟
‏HTTP یک پروتکل برای انتقال اطلاعات بین مرورگر و وب‌سرور است.

‏HTTPS چیست؟
‏HTTPS نسخه امن HTTP است که اطلاعات را هنگام انتقال رمزگذاری می‌کند.

‏چه تفاوتی بین HTTP و HTTPS وجود دارد؟
‏در HTTP اطلاعات رمزگذاری نمی‌شوند، اما در HTTPS اطلاعات رمزگذاری شده و امنیت بیشتری دارند.

‏چرا امروزه بیشتر وب‌سایت‌ها از HTTPS استفاده می‌کنند؟
‏زیرا HTTPS از اطلاعات کاربران مانند رمز عبور و اطلاعات شخصی هنگام انتقال محافظت می‌کند.

‎4. URL

‏URL چیست؟
‏URL آدرس یک منبع در اینترنت است؛ مانند آدرس یک صفحه وب، فایل یا API.

‏یک URL را بررسی کنید و قسمت‌های مختلف آن را مشخص کنید.

‏مثال:

‎https://www.example.com/products?id=25

‎https
‏پروتکل ارتباطی است.

‎www
‏زیردامنه است.

‎example.com
‏دامنه سایت است.

‎products
‏مسیر یا Path است.

‎?id=25
‏Query String و پارامتر درخواست است.

‏5. GET و POST

‏GET چیست؟
‏GET برای دریافت اطلاعات از سرور استفاده می‌شود.

‏POST چیست؟
‏POST برای ارسال اطلاعات به سرور استفاده می‌شود.

‏چه تفاوتی بین GET و POST وجود دارد؟
‏GET معمولاً برای دریافت اطلاعات استفاده می‌شود و داده‌ها می‌توانند در URL قرار بگیرند. POST برای ارسال اطلاعات استفاده می‌شود و داده‌ها معمولاً در بدنه درخواست قرار می‌گیرند.

‏برای چه نوع درخواست‌هایی معمولاً از GET استفاده می‌کنیم؟
‏برای دریافت اطلاعات، مانند دریافت لیست محصولات.

‏مثال:

‎GET https://api.example.com/products

‏برای چه نوع درخواست‌هایی معمولاً از POST استفاده می‌کنیم؟
‏برای ارسال یا ثبت اطلاعات، مانند ایجاد یک کاربر جدید.

‏مثال:

‎POST https://api.example.com/users

‏6. JSON و XML

‏JSON چیست؟
‏JSON یک فرمت ساده و رایج برای ذخیره و انتقال اطلاعات بین برنامه‌ها و سرورهاست.

‏XML چیست؟
‏XML یک فرمت برای ذخیره و انتقال اطلاعات است که داده‌ها را با استفاده از تگ‌ها مشخص می‌کند.

‏چه کاربردی دارند؟
‏هر دو برای انتقال و تبادل اطلاعات بین سیستم‌ها، مخصوصاً در APIها، استفاده می‌شوند.

‏چه تفاوت‌هایی با یکدیگر دارند؟
‏JSON معمولاً کوتاه‌تر و ساده‌تر است و در APIهای امروزی بسیار رایج است. XML از تگ‌ها استفاده می‌کند و معمولاً طولانی‌تر است.

‏اطلاعات Student با JSON:

‎{
‎"name": "Ali",
‎"age": 20,
‎"studentId": 101
‎}

‏اطلاعات Student با XML:

‎<Student>
‎    <Name>Ali</Name>
‎    <Age>20</Age>
‎    <StudentId>101</StudentId>
‎</Student>
